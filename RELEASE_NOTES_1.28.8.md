# KopelaEQ 1.28.8

1.28.8 is an icon-only refinement over 1.28.7.

## Changed

- Replaced the previous catgirl icon artwork with the cleaner black-and-white manga catgirl version without cheek marks.
- Rebuilt all Chrome icon sizes from the same full composition so ears, hair and headphones remain inside the canvas instead of using aggressive size-specific crops.
- Reduced empty transparent padding and applied light small-size sharpening so the 16/32 px toolbar icons remain recognizable.

## Unchanged

- DSP and frozen EQ baseline.
- Protection tuning and audio topology.
- State schema and persistence.
- Async/concurrency hardening from 1.28.6.
- Permissions and CSP.
